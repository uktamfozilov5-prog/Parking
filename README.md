# ⚡ SmartPark Pro — Интеллектуальная система управления парковкой

Полноценный Fullstack-проект интеллектуальной системы управления автоматизированной парковкой на базе **Node.js (Express)** и **Vanilla JavaScript / CSS / HTML** с современным интерфейсом в темных фиолетовых тонах и эффектом неонового свечения (Dark Purple Glassmorphism).

---

## 📋 Основные характеристики и бизнес-логика

### 1. Архитектура парковочных мест (ровно 15 мест)
* **Места №1 – №5 (EV Charging)**:
  - Выделенная зона со станциями скоростной зарядки для электромобилей.
  - **Тариф**: `8 000 сум / час`.
  - **Бизнес-правило**: Строгая валидация на клиенте и сервере. Автомобиль с двигателем внутреннего сгорания (ДВС) **не может** занять места 1–5.
* **Места №6 – №15 (Стандарт)**:
  - Стандартные парковочные места для любых легковых автомобилей.
  - **Тариф**: `5 000 сум / час`.

### 2. Авторизация и Ролевая модель
* **JWT-авторизация**: токены хранятся в `localStorage` и передаются через заголовок `Authorization: Bearer <token>`.
* **Роли пользователей**:
  - `User` (Водитель): просмотр интерактивной карты, парковка своего автомобиля с валидацией типа ТС, завершение своей парковки с получением детального электронного чека, история личных сессий.
  - `Admin` (Администратор парковки): доступ к дашборду со статистикой в реальном времени (общая выручка, текущие начисления, процент занятости), мониторинг всех занятых машин, **ручное принудительное освобождение зависших мест**, экстренный сброс статусов мест и просмотр полной истории всех транзакций.

### 3. Биллинг и расчет стоимости
* При освобождении места автоматически фиксируется точное время выезда (`exitTime`).
* Вычисляется продолжительность стоянки в минутах и часах.
* **Правило расчета**: оплата производится за каждый начавшийся час (округление вверх, минимум 1 час):
  $$\text{Итого} = \max(1, \lceil \text{Минуты} / 60 \rceil) \times \text{Тариф}$$
* Формируется детальный **электронный чек (Receipt)**:
  - Уникальный номер чека (`#REC-2026-XXXX`);
  - Номер и категория места (EV Charging / Стандарт);
  - Госномер и марка автомобиля;
  - Время въезда и время выезда;
  - Общее время стоянки и оплачиваемое количество часов;
  - Примененный тариф (`8 000 сум/ч` или `5 000 сум/ч`);
  - Итоговая сумма к оплате в сумах (`сум`);
  - Кнопка вызова печати термо-чека (`window.print()`).

## 🚀 Установка и запуск

### Шаг 1. Переход в папку проекта
Откройте терминал в папке проекта:
```bash
cd day12
```

*(Или можно запускать прямо из корневой папки `backendGw100`)*

### Шаг 2. Установка зависимостей
*(В Windows PowerShell рекомендуется использовать `npm.cmd`)*:
```bash
npm install
# или в Windows PowerShell:
npm.cmd install
```

### Шаг 3. Запуск сервера
Режим запуска:
```bash
npm start
# или в режиме разработки с автоперезагрузкой:
npm run dev
```

### Шаг 4. Открытие в браузере
Перейдите по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

## 📡 REST API Спецификация

### Авторизация
* `POST /api/auth/register` — Регистрация нового водителя или администратора.
* `POST /api/auth/login` — Вход в систему с получением JWT токена.
* `GET /api/auth/me` — Получение профиля текущего пользователя по токену.

### Парковка
* `GET /api/spots` — Получение статуса всех 15 мест и текущих счетчиков.
* `GET /api/spots/:id` — Детальная информация по конкретному месту.
* `POST /api/spots/:id/park` — Въезд автомобиля на свободное место (с валидацией типа ТС).
* `POST /api/spots/:id/unpark` — Выезд автомобиля с парковки, расчет биллинга и формирование чека.
* `GET /api/user/receipts` — История чеков текущего пользователя.

### Административная панель
* `GET /api/admin/stats` — Сводная финансовая статистика и показатели занятости.
* `GET /api/admin/receipts` — Полная история всех завершенных парковочных сессий.
* `POST /api/admin/spots/:id/force-release` — Принудительное освобождение зависшего места.
* `POST /api/admin/reset-all` — Экстренный сброс всех мест с автоматическим архивированием сессий.
